NOTE_001
PERSONAL LOG

Kenapa saya jatuh cinta pada coding?

Awalnya coding terlihat seperti barisan simbol yang rumit. Setelah mencoba, saya sadar bahwa coding sebenarnya adalah cara untuk berbicara dengan komputer dan mengubah ide menjadi pengalaman.

Setiap error terasa seperti petunjuk kecil. Dari sana saya belajar bahwa bagian paling menyenangkan bukan hanya hasil akhirnya, tetapi proses mencari tahu kenapa sesuatu belum bekerja.

NOTE_002
TECH / 05 MIN

Membongkar cara kerja internet.

Ketika kita membuka sebuah website, browser mengirim permintaan ke server melalui jaringan. DNS membantu menerjemahkan nama domain menjadi alamat IP, lalu server mengirimkan kembali data yang dibutuhkan.

Yang terlihat seperti satu klik sederhana sebenarnya adalah percakapan cepat antara browser, server, dan banyak perangkat lain. Memahami alurnya membuat teknologi terasa jauh lebih dekat.

NOTE_003
MINDSET / 04 MIN

Belajar teknologi tanpa takut tersesat.

Dunia teknologi terlalu luas untuk dikuasai sekaligus. Saya memilih mulai dari satu pertanyaan, memecahnya menjadi percobaan kecil, lalu mencatat hal yang saya temukan.

Tidak semua eksperimen berhasil, dan itu bukan masalah. Setiap kegagalan memberi arah baru. Yang penting adalah tetap penasaran dan terus membuat sesuatu, sekecil apa pun.
